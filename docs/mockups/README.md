# Screen mockups

Design mockups of the main screens, drawn in HTML/SVG to match the SwiftUI layouts and `Theme.swift` colours, using the
app's built-in example data. Headline figures (safe to spend, cash forecast, bills, debt-free dates, payoff order) come from
running the app's own calculation code. Category spending figures are illustrative.

They are **not** simulator screenshots: those need a Mac with Xcode. Regenerate by opening `screens.html` in a browser.
